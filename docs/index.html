Comment lire ça

Note /100 : 50 = pas mieux que dire le même % à tout le monde. 100 = parfait, ça n'arrive pas. En sport, 55 à 60 c'est un bon modèle. Sous 50, la version est à jeter.

Calibration : la barre bleue est le % réel de 2+ tirs dans chaque tranche, le trait rouge est le % prédit moyen. Barre qui arrête au trait = le modèle dit vrai. Barre plus courte = trop optimiste.

Top 10 : sur les 10 meilleurs choix de chaque soir, combien ont fait 2+ tirs vs combien le modèle en attendait.

Brier : erreur moyenne au carré, plus bas = mieux. Les scratchés ne comptent pas.

Avec moins de 500 prédictions gradées, les différences entre versions peuvent être de la chance.
